# ConceptRoutes

> 来源：DesignBrief — 批量图片处理 Web 工具
> 诉求：现代科技感、大气、暗色主题优先、上传区域核心地位
> 路径：路径 B（跳过预制模板，从零定制）

---

## 方向 A：暗物质实验室（Dark Matter Lab）

**主张**：反抗传统工具型界面的"白色面板 + 灰色边框"刻板印象。用深邃的暗色背景模拟实验室环境，让上传区域成为唯一的光源——用户拖入图片就像把样本送入分析舱。

### 字体配对
- Display: **DM Sans 600** — 几何感强，x-height 大，在暗底上可读性极好，现代但不冷感
- Body: **DM Sans 400** — 同族字体保证一致性，Regular 字重足够轻盈
- 配对理由: DM Sans 的几何骨架配合暗色背景，营造精确、理性、可信赖的实验室氛围。不引入衬线体避免传统工具感

### 布局概念

### 签名元素
**发光的上传区域边框**：上传区使用微弱的 cyan 发光边框动画（`box-shadow` 脉冲），模拟"扫描舱待命"状态。拖入文件时边框亮度增强，给用户即时的视觉反馈——这是整个页面唯一有动画光效的区域，引导视线自然聚焦。

## 方向 B：精密仪器（Precision Instrument）

**主张**：反抗花哨的渐变和多余的装饰。像一台徕卡相机或示波器——深灰金属感、高精度排版、每个像素都有存在理由。信息密度适中，留白克制但精准。

### 配色方案
| 角色 | 色名 | 色值 | OKLCH |
|------|------|------|-------|

| 面板背景 | Gunmetal | `#222228` | oklch(0.22 0 270) |
| 卡片背景 | Raised Gray | `#2a2a32` | oklch(0.25 0 270) |

| 辅助强调 | Chrome Blue | `#5b9bd5` | oklch(0.62 0.13 250) |
| 主文字 | Silver | `#d4d4d8` | oklch(0.86 0 0) |
| 次文字 | Steel | `#71717a` | oklch(0.52 0 0) |
| 成功色 | Signal Green | `#4ade80` | oklch(0.75 0.18 150) |
| 错误色 | Signal Red | `#f87171` | oklch(0.65 0.22 25) |

### 字体配对
- Display: **Geist 600** — Vercel 出品，极其干净利落，专为 UI 而生，字间距精确
- Body: **Geist 400** — 同族，Regular 字重在深色背景上呈现恰到好处的灰度
- 配对理由: Geist 的设计哲学是"零干扰"，每个字符都被优化到最精简。配合金属灰色调，让工具界面像精密仪器一样可信。不引入衬线体保持纯工具属性

### 签名元素
**网格背景的上传区**：上传区域背景使用微弱的等距网格线（`background-image` 用 SVG pattern），像工程图纸或 PCB 设计，暗示精确和秩序。网格密度随窗口大小自适应，维持每格约 24px。

## 方向 C：液态光（Liquid Light）

**主张**：反抗暗色主题常见的"死黑"沉闷感。用深色但不黑的基底 + 大面积柔和光晕 + 磨砂玻璃材质，让工具界面像 macOS 控制中心一样通透、轻盈。科技感来自光影层次，而非刺眼的霓虹。

|------|------|------|-------|
| 页面背景 | Midnight Blue | `#0f1119` | oklch(0.14 0.03 265) |
| 面板背景 | Frosted Glass | `rgba(22,24,35,0.85)` | — |
| 卡片背景 | Raised Glass | `rgba(30,32,45,0.7)` | — |
| 主强调色 | Electric Blue | `#3b82f6` | oklch(0.58 0.22 260) |
| 辅助强调 | Soft Violet | `#8b5cf6` | oklch(0.52 0.22 290) |
| 主文字 | Cloud White | `#f1f5f9` | oklch(0.94 0.01 260) |
| 次文字 | Mist Gray | `#94a3b8` | oklch(0.67 0.02 255) |
| 成功色 | Mint | `#34d399` | oklch(0.74 0.15 165) |
| 错误色 | Coral | `#fb7185` | oklch(0.64 0.21 15) |

### 字体配对
- Display: **Plus Jakarta Sans 600** — 几何人文主义无衬线，圆润但不幼稚，适合大字号标题
- Body: **Plus Jakarta Sans 400** — 同族 Regular，行高 1.6 保证长文本舒适
- 配对理由: Plus Jakarta Sans 的笔画收尾微带弧度，配合磨砂玻璃材质，软化了纯工具界面的冷酷感。它既有科技产品的精确，又保留了一丝温度

### 布局概念
单页垂直流，上传区在首屏居中放大（占据 50%+ 视觉面积）。预设标签以悬浮 chip 形式置于上传区上方。设置面板以磨砂玻璃卡片叠放在右下角，可折叠。

### 签名元素
**磨砂玻璃材质的设置面板**：右侧设置面板使用 `backdrop-filter: blur(20px)` 实现毛玻璃效果，悬浮在页面上方而非嵌入。面板边缘有微弱的蓝紫光晕投影（`box-shadow` 使用半透明强调色），像一块浮在暗色液体上的发光玻璃板。所有卡片和按钮也使用轻微的半透明背景，创造空间层次。

## 方向对比

| 维度 | A: 暗物质实验室 | B: 精密仪器 | C: 液态光 |
|------|:--:|:--:|:--:|
| 氛围 | 深邃神秘、探索感 | 冷静克制、专业感 | 通透轻盈、未来感 |
| 暗度 | 最深（几乎纯黑） | 深灰金属 | 深蓝灰（不完全黑） |
| 材质感 | 发光边框 | 金属网格纹理 | 磨砂玻璃光晕 |
| 强调色策略 | 青 + 暖橙双色 | 白色为主，蓝为辅 | 蓝 + 紫双色光晕 |
| 适合印象 | 像科幻电影里的分析仪器 | 像专业摄影师的暗房工具 | 像 Apple 出品的专业工具 |
| 信息密度 | 中等 | 中偏高 | 中偏低 |
