# DesignBrief

## 产品定位
批量图片处理 Web 工具——支持压缩、格式转换（JPEG/PNG/WebP/ICO）、裁切缩放、预设模板一键应用。技术栈 React + Vite + TailwindCSS 前端，Node.js + Sharp 后端。所有处理在服务器端完成，处理完自动打包 ZIP 下载。

## 目标用户
- **设计师**：需要快速批量调整图片尺寸、格式、压缩率
- **开发者**：WebP 转换、Favicon 生成、图片优化
- **普通用户**：社交媒体图片处理、照片批量压缩

## 页面唯一目标
让用户**快速上传图片 → 直观选择处理方式 → 一键处理 → 获取结果**。上传是核心交互的起点，必须占据页面视觉中心。

## 当前问题（来自用户反馈）
1. **预设模板占比过大**：8 个全尺寸卡片占据首屏大量空间，预设只是快捷入口
2. **上传区域不够突出**：核心交互区太小气，应该更大更醒目
3. **整体风格不够大气现代**：需要科技感和现代性，不是传统工具型界面

## 输出格式
高保真单文件 HTML 原型（可浏览器直接打开），保留所有现有功能逻辑。
